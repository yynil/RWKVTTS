# 🎤 RWKV ASR Gradio Web应用

基于Gradio的语音识别Web应用，支持录音和文件上传识别。

## ✨ 特性

- 🎙️ **录音识别**: 支持浏览器录音，实时语音识别
- 📁 **文件上传**: 支持多种音频格式上传识别
- 🌍 **多语言支持**: 支持中文和英文识别
- 🎨 **现代化界面**: 基于Gradio的友好用户界面
- ⚡ **简单易用**: 无需复杂配置，开箱即用

## 🚀 快速开始

### 1. 环境准备

```bash
cd webgui

# 激活RWKVTTS_py311环境
conda activate RWKVTTS_py311

# 安装最新版Gradio
./install_gradio.sh

# 或手动安装依赖
pip install -r requirements.txt
```

### 2. 启动应用

#### 方法1: 使用启动脚本（推荐）
```bash
./start.sh
```

#### 方法2: 直接运行
```bash
# 录音专用应用（推荐）
python recording_gradio_app.py

# 简化版应用
python simple_gradio_app.py

# 完整版应用
python gradio_app.py
```

### 3. 访问应用

打开浏览器访问: `http://localhost:7860`

## 🎤 录音功能使用

### 录音步骤
1. **选择语言**: 选择中文或English
2. **开始录音**: 点击录音按钮，允许浏览器访问麦克风
3. **说话**: 对着麦克风说话
4. **停止录音**: 录音会自动停止
5. **开始识别**: 点击"开始识别"按钮
6. **查看结果**: 识别结果将显示在右侧

### 文件上传识别
1. **选择语言**: 选择中文或English
2. **上传文件**: 点击"上传音频文件"选择音频文件
3. **开始识别**: 点击"开始识别"按钮
4. **查看结果**: 识别结果将显示在右侧

## 🔧 命令行参数

```bash
python recording_gradio_app.py --help
```

### 主要参数

- `--audio-lm-path`: 音频语言模型路径
- `--llm-path`: 大语言模型路径
- `--whisper-path`: Whisper模型路径
- `--tokenizer-path`: 分词器路径
- `--device`: 设备类型 (cuda:0/cpu)
- `--dtype`: 数据类型 (float16/float32/bfloat16)
- `--host`: 服务器主机地址 (默认: 0.0.0.0)
- `--port`: 服务器端口 (默认: 7860)
- `--share`: 创建公共链接
- `--debug`: 启用调试模式

### 示例命令

```bash
# 使用默认配置
python recording_gradio_app.py

# 自定义端口
python recording_gradio_app.py --port 8080

# 创建公共链接
python recording_gradio_app.py --share

# 使用CPU
python recording_gradio_app.py --device cpu --dtype float32

# 调试模式
python recording_gradio_app.py --debug
```

## 🔍 故障排除

### 常见问题

#### 1. 录音功能无法使用
**原因**: 浏览器权限问题
**解决方案**:
- 确保浏览器允许麦克风权限
- 尝试不同的浏览器
- 检查系统麦克风权限

#### 2. 模型加载失败
**原因**: 模型路径错误或文件不存在
**解决方案**:
- 检查模型路径是否正确
- 确保所有模型文件存在
- 检查文件权限

#### 3. 识别结果不准确
**原因**: 音频质量问题或模型问题
**解决方案**:
- 确保录音清晰，无噪音
- 检查音频格式是否支持
- 尝试不同的音频文件

#### 4. 服务器启动失败
**原因**: 端口被占用或依赖缺失
**解决方案**:
- 更换端口号
- 检查依赖是否安装完整
- 查看错误日志
